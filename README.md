# Tiny Metronome · 轻量开源在线节拍器

免费、开源、零依赖的在线节拍器，用 Web Audio API 独立实现，所有代码与音色均为原创，可离线使用。

> 小而全：6 个文件、约 64KB、零依赖、零构建——双击 `index.html` 就能跑，克隆一份放进 U 盘也是完整的节拍器。

A tiny but full-featured, zero-dependency online metronome, independently implemented with the Web Audio API. Works offline.

## 功能 / Features

- **BPM 20–300**：数字输入、滑块、± 按钮（长按加速）、点击测速（Tap Tempo）
- **拍号**：分子 1–16，分母 2/4/8/16 自由组合（2/4、3/4、4/4、6/8、7/8、12/8……）
- **9 种节奏型**（含特殊节奏型，记谱图标选择）：
  - 基础：四分 ♩ / 八分 ♪♪ / 三连音 ♪♪♪ / 十六分 ♬♬
  - 特殊：附点（长-短）/ 反附点（短-长）/ 前八后十六 / 前十六后八 / 切分 ♬♪♬
  - 每拍下的子拍圆点按节奏型的实际位置显示，切换节奏型在下一拍干净生效
  - 记谱图标与名称随拍号分母（2/4/8/16）自动换算时值：如 8/x 下「八分」型显示为两个十六分音符
- **逐拍三态**：点击节拍圆点循环切换 重音 / 普通 / 静音（静音拍整拍静默，含子拍），可组合出复杂重音练习
- **4 种合成音色**：响板 / 电子音 / 底鼓 / 踩镲（无音频文件，全部实时合成）
- **定时停止**（1–30 分钟，练习好帮手）
- **内置使用说明**：右上角 ？ 弹窗覆盖全部页面功能（中英双语）
- **速度术语**：Grave 庄板 → Prestissimo 最急板 实时显示
- **中英双语界面**、**深色/浅色主题**（跟随系统）、设置自动保存
- 响应式布局，手机/平板/桌面均可使用；标签页切到后台依然保持精准

## 键盘快捷键 / Shortcuts

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 停止 |
| `↑` `↓`（或 `←` `→`） | BPM ±1 |
| `Shift + ↑/↓` | BPM ±5 |
| `T` | 点击测速 |

## 使用 / Usage

无需安装、无需构建。任选其一：

1. **直接打开**：双击 `index.html` 即可运行。
2. **本地服务**：`python -m http.server 8080`，然后访问 `http://localhost:8080`。
3. **部署**：把整个目录上传到任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储），没有构建步骤。

> 注：部分浏览器要求用户先与页面交互才允许播放声音——点击播放按钮即可。

## 技术要点 / How it works

- 采用 Web Audio API 的 **lookahead 调度模式**（参考 *A Tale of Two Clocks*）：`setInterval` 每 25ms 醒来，按 **音频硬件时钟**（`AudioContext.currentTime`）提前约 0.12s 精确排定音符，因此节奏精度不受主线程卡顿影响。
- 标签页切到后台时定时器会被浏览器限流，引擎会自动加大 lookahead（约 1.6s）保证不断拍。
- **节奏型引擎**：每拍可定义任意点击位置（0–1 的偏移数组），因此支持附点、切分等非均匀节奏；切换在下一拍正拍干净生效，旧版「均匀分割」设置自动迁移。
- 所有音色（响板/电子/底鼓/踩镲）用振荡器 + 噪声缓冲 + 包络实时合成，零采样、零外部资源。
- 视觉节拍由节拍圆点的脉冲动画呈现，事件由音频时钟精确派发，与声音严格同步。
